# Workspaces, spaces e listas

## Workspace

O workspace é a fronteira de tudo: membros, tarefas, docs, chat e configurações pertencem a um
workspace e não vazam para outro. Uma pessoa pode participar de vários e alterna entre eles pela
barra lateral.

- **Criar**: em Workspaces, "Novo workspace". Quem cria é o **Owner**.
- **Arquivar**: Configurações → Geral. O workspace some da lista principal de todos os membros,
  mas nada é apagado; dá para desarquivar quando quiser.
- **Nome e cor** aparecem para todos, na barra lateral e nos convites.

## Membros e papéis

| Papel | Pode |
|---|---|
| **Owner** | Tudo, inclusive plano e cobrança, e arquivar o workspace |
| **Admin** | Gerenciar membros, configurações, integrações, fluxos de status |
| **Member** | Usar o workspace: tarefas, docs, chat |

Convites são feitos em **Membros**, por e-mail. Quem ainda não tem conta recebe um link para
criar a conta e já entrar no workspace; quem tem conta recebe uma notificação. Ninguém é
adicionado sem aceitar o convite.

## Spaces e listas

- Um **space** agrupa listas por assunto (Operações, Produto, um cliente).
- Uma **lista** é onde as tarefas vivem. Cada lista tem as próprias colunas de status, as próprias
  regras de transição e os próprios campos personalizados e etiquetas.
- As visões de uma lista: **Lista**, **Quadro**, **Backlog**, **Calendário** e **Gantt**. Todas
  mostram as mesmas tarefas; só a apresentação muda.

## Configurações do workspace

Em **Configurações** (Owner e Admin):

- **Geral**: nome, cor, plano e arquivamento.
- **Fluxo de trabalho**: as colunas de status e as regras de transição de cada lista.
- **Integrações**: chaves de API e webhooks de saída, para sistemas externos (veja
  [Integrações](../integracoes/index.md)).
