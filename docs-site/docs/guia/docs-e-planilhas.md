# Docs e planilhas

Cada workspace tem uma área de **Docs**: documentos de texto e planilhas que a equipe edita
junto, em tempo real.

## Documentos

- Editor de texto rico: títulos, listas, negrito, links, imagens coladas, tabelas.
- **Edição simultânea**: várias pessoas no mesmo doc veem as alterações umas das outras na hora,
  com a presença de quem está na página.
- **Importar arquivos**: um `.docx` ou `.md` vira um doc editável; outros arquivos ficam
  guardados como anexo do workspace, para baixar.
- Cite uma tarefa pelo código (`TASK-12`) para linkar.

## Planilhas

- Grade com fórmulas básicas, formatação e edição simultânea.
- **Exportar** para `.xlsx` a qualquer momento.

## Quem vê o quê

Docs e planilhas pertencem ao workspace: todos os membros leem e editam. Para apagar um arquivo
importado, é preciso ser Admin ou quem o enviou.
